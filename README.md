# FinanceHub — תובנות פיננסיות

אתר פיננסי בעברית (RTL): חיפוש מניות ותעודות סל, נתונים פיננסיים וגרפים, רשימת מעקב ותיק השקעות עם מדדי ביצועים.

## יכולות

- **תובנות** — חיפוש לפי שם/סימול, קטגוריות (S&P 500, הכי חמות, צמיחה, דיבידנד, תעודות סל, ישראל) ופס מדדים עליון.
- **עמוד מניה** — גרף מחיר (חודש עד מקסימום), נתונים עיקריים (שווי שוק, P/E, EPS, בטא, תשואת דיבידנד...), גרפי הכנסות מול הוצאות, רווח נקי, שולי רווח, EPS, תזרים חופשי (שנתי/רבעוני), תשואת דיבידנד ודיבידנד למניה לאורך השנים.
- **עמוד תעודת סל** — דמי ניהול, נכסים מנוהלים, אחזקות עיקריות, חלוקה לסקטורים, תשואה שנתית, מחיר ודיבידנדים לאורך זמן.
- **משתמשים** — הרשמה/התחברות (סיסמה מוצפנת ב-bcrypt, סשן JWT בעוגייה httpOnly).
- **רשימת מעקב** ו**תיק השקעות** — עסקאות קנייה/מכירה (המחיר ממולא אוטומטית לפי מחיר הסגירה בתאריך), אחזקות, רווח ממומש/לא ממומש, דיבידנדים, ותצוגה בדולר או בשקל.
- **ביצועים** — TWR (תשואה משוקללת זמן) ו-MWR (IRR, תשואה משוקללת כסף), שנתי כשהתקופה ארוכה משנה. השוואה ל-S&P 500, נאסד״ק, דאו ג׳ונס ות״א 35, כולל "מה היה קורה אילו אותם תזרימים הושקעו במדד".

## הרצה מקומית

```bash
npm install
cp .env.example .env      # ולעדכן AUTH_SECRET
npx prisma db push        # יצירת מסד SQLite
npm run dev               # http://localhost:3000
```

בדיקות: `npm test` · בדיקת טיפוסים: `npm run typecheck` · בנייה: `npm run build`.

## מקור נתונים

ברירת המחדל היא Yahoo Finance דרך הספרייה `yahoo-finance2` (ללא מפתח API). אם המקור לא זמין, האתר עובר אוטומטית
ל**נתוני הדגמה** סינתטיים ומציג על כך באנר. `MARKET_DATA_PROVIDER=mock` מכריח נתוני הדגמה.
Yahoo הוא מקור לא רשמי ומיועד לשימוש אישי בלבד — לשימוש מסחרי צריך ספק עם רישיון (למשל TASE Data Hub לנתוני הבורסה בת״א, או EODHD / Polygon / Financial Modeling Prep).

### החלפת ספק

1. מממשים את הממשק `MarketDataProvider` (`src/lib/market/types.ts`) בקובץ חדש, למשל `src/lib/market/eodhd.ts`.
2. רושמים אותו ב-`PROVIDERS` שב-`src/lib/market/providers.ts`.
3. מגדירים `MARKET_DATA_PROVIDER=<שם הספק>` (שם לא מוכר חוזר ל-Yahoo).

שאר האתר ניגש לנתונים רק דרך `market` ב-`src/lib/market/index.ts`, כך שהמטמון והנפילה לנתוני הדגמה עובדים אוטומטית לכל ספק.

## מבנה

| נתיב | תוכן |
|---|---|
| `src/app/insights` | עמוד התובנות |
| `src/app/asset/[symbol]` | עמוד מניה / תעודת סל / מדד |
| `src/app/watchlist`, `src/app/portfolio` | רשימת מעקב ותיק |
| `src/app/actions.ts` | Server Actions (התחברות, מעקב, עסקאות) |
| `src/lib/market` | ספקי נתונים (Yahoo + הדגמה), מטמון ונפילה לגיבוי |
| `src/lib/portfolio/metrics.ts` | חישובי TWR / XIRR / השוואה למדדים (עם בדיקות) |

### הנחות בחישוב התיק
- קנייה = הפקדה לתיק, מכירה = משיכת התמורה. דיבידנדים נשארים בתיק כמזומן ונחשבים כתשואה.
- תשואת המדדים היא תשואת מחיר (ללא דיבידנדים), מומרת למטבע הבסיס.
- מניות בת״א מתומחרות באגורות (ILA) ומומרות אוטומטית; המרות מט״ח לפי שער יומי.

## פריסה לייצור
החליפו ב-`prisma/schema.prisma` את `provider` ל-`postgresql`, הגדירו `DATABASE_URL` ו-`AUTH_SECRET`, והריצו `npx prisma db push`.
